# Building a Retail Sales Data Agent on Databricks

## Project Objective
This project demonstrates how to build and evaluate a retail sales analytics agent in Databricks using structured retail transaction data. The agent was designed to answer business questions and provide data-driven insights.

---

## Tools Used
- Databricks
- Databricks SQL
- Unity Catalog
- AI Agent / Genie Space
- SQL
- Microsoft Word
- GitHub

---

## Dataset Overview
Dataset Name:
`retail_sales_data`

Dataset contains:
- Retail transactions
- Product categories
- Sales values
- Customer demographics
- Time-based sales information

---

## Steps Followed

### 1. Dataset Preparation
- Uploaded CSV into Databricks
- Registered as table
- Added metadata and descriptions

### 2. Agent Development
- Created retail sales analytics agent
- Connected to `retail_sales_data`
- Added business instructions

### 3. Agent Testing
- Asked business questions
- Generated analytical responses

### 4. Validation
- Verified outputs using SQL
- Cross-checked results with source data

---

## Example Business Questions
- What are total sales?
- Which category performs best?
- What are monthly sales trends?
- Which age group contributes most to revenue?

---

## Key Insight
Reliable AI analysis requires validation against source data. SQL verification was used to confirm agent outputs.
